FAIRYGUARD — ЛАБОРАТОРНАЯ РАБОТА №1
Автор: Жбанова София Романовна
Группа: ИДБ-23-11

Запуск:
1. Откройте папку проекта в Visual Studio.
2. Откройте fairyguard.py.
3. Выберите Python 3.
4. Запустите Start Without Debugging.

Внешние библиотеки не нужны — используется tkinter.

ВАЖНО ПРО ФАЙЛ ДАННЫХ
При первом запуске рядом с fairyguard.py автоматически создается accounts.json.
В нем хранятся:
- имя пользователя;
- пароль;
- блокировка;
- включение/отключение ограничения пароля.

При первом запуске в файле будет только ADMIN с пустым паролем.
При первом входе ADMIN программа потребует установить новый пароль.

Если рядом лежит security.db от предыдущей версии и он содержит JSON,
программа автоматически перенесет эти учетные записи в accounts.json.

ВАРИАНТ №7
При включенном ограничении пароль должен содержать:
- хотя бы одну цифру;
- хотя бы один знак + - * / %.

Пример подходящего пароля: Fairy7+

КАК ПРОВЕРИТЬ
ADMIN:
- может сменить пароль;
- может добавить нового пользователя;
- может открыть весь список пользователей;
- может блокировать/разблокировать пользователя;
- может включать/отключать ограничение пароля;
- может завершить программу.

Обычный пользователь:
- может сменить только свой пароль;
- может завершить программу;
- не может сам зарегистрироваться;
- не может добавлять и редактировать других пользователей.

Новый пользователь создается ADMIN с пустым паролем.
При первом входе пользователь сам устанавливает пароль.
